Home Lab Backups

Home Lab Backups is a private utility operated by plcharbonneau to keep encrypted backups of the operator’s own home lab in the operator’s Google Drive.

It uses restic for encryption and recovery, and rclone for transfers. This is a personal tool, with no public registration or hosted backup service.

Google Drive access

The utility requests only drive.file. It can create and manage backup files it creates or files explicitly opened with it. It does not request general access to the account’s Google Drive.

Backup contents are encrypted before upload. This website contains information about the utility; it provides no access to backup files or credentials.
