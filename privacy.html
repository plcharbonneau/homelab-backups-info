Home Lab Backups

Privacy policy

Effective October 29, 2026.

Purpose and operator

Home Lab Backups is operated by plcharbonneau solely for the operator’s personal backups. It is not a service offered to other users.

Data accessed and used

The utility uses Google OAuth authorization and the drive.file scope to create, list, read, update and delete its own backup repository files in the operator’s Google Drive. It processes repository metadata and encrypted backup objects only for backup, retention, integrity checks and recovery.

OAuth credentials are stored in protected configuration files on the operator’s devices. Local backup data is encrypted by restic before it is sent to Google Drive. The decryption password is kept separately from the cloud repository.

Sharing and other uses

Google receives the encrypted repository files and API requests needed to store and retrieve them. The utility does not sell Google user data, use it for advertising, or use it to train artificial intelligence models. It does not disclose that data to other parties for unrelated purposes.

Home Lab Backups’ use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The operator controls backup retention and deletion. Older snapshots may be retained for recovery and migration validation. Revoking access through Google Account connections stops further authorized access; it does not automatically delete existing backup files. The operator may delete the repository directly in Google Drive and remove local credentials and copies.

This website

These static information pages have no forms, analytics scripts or application cookies. GitHub Pages hosts the site and may process ordinary request information under GitHub’s privacy statement.

Contact

For questions about this personal utility, use the contact options on the operator’s public GitHub profile. Do not send credentials or backup contents.
